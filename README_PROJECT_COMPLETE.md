## 🚀 HOW TO RUN

### Already Running?
- Open: http://127.0.0.1:8001
- Login with test credentials above

### Start From Scratch?
```bash
cd d:\Download\cobalaravel\studentpoint

# First time only
composer install
npm install
cp .env.example .env
php artisan key:generate

# Configure database in .env file:
# DB_DATABASE=epoin
# DB_USERNAME=root
# DB_PASSWORD=

# Run database setup
php artisan migrate:fresh
php artisan db:seed

# Start server
php artisan serve --port=8001

# Open browser: http://127.0.0.1:8001
```
